# Add .bib file

Add .bib file template to help cite the datasets in a package from our
universe.

## Usage

``` r
add_bib(datacube, dataset)
```

## Arguments

- datacube:

  Name of the datacube dataset is a part of

- dataset:

  Name of the dataset

## Value

A .bib template saved to the data-raw folder to be completed

## Examples

``` r
if (FALSE) { # \dontrun{
add_bib("states", "COW")
} # }
```
